# Database Setup

This folder contains the SQL files required to set up the Smart Recruitment Analytics database locally.

## Requirements

- MySQL 8+
- MySQL Workbench (recommended)

## Files

- `schema.sql` - Creates the database and all required tables.
- `seed.sql` - Inserts the project's sample recruitment data.
- `README.md` - Database setup instructions.

## Setup Instructions

### 1. Clone the repository

Clone the project and switch to the required branch:

```bash
git clone https://github.com/ROVAH-grp/smart-recruitment-analytics.git
cd smart-recruitment-analytics
git checkout feature/frontend-backend
